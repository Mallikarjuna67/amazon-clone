# 🛒 Amazon Clone

A responsive **Amazon Clone** website built as a web development project to practice and demonstrate front-end development skills.

This project recreates the look and feel of the Amazon shopping website, including the navigation bar, product sections, search bar, categories, and shopping interface.

> ⚠️ This project is created for educational and portfolio purposes only. It is not affiliated with or endorsed by Amazon.

---

## 📌 Project Overview

The Amazon Clone is a front-end e-commerce website inspired by Amazon's user interface.

The main objective of this project is to understand how modern e-commerce websites are designed and to improve practical skills in:

- HTML
- CSS
- User Interface Design
- Git & GitHub

---

## 🚀 Features

- 🏠 Amazon-inspired home page
- 🔍 Search bar
- 📦 Product sections
- 🛍️ Shopping interface
- 🧭 Navigation bar
- 🖼️ Product images
- 🏷️ Product categories
